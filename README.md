# UNISA-Gaming
Il sito è rivolto a giocatori e appassionati di videogiochi, offrendo un catalogo di console, videogiochi e accessori gaming. Gli utenti potranno consultare, confrontare e acquistare i prodotti in modo semplice e sicuro. Sarà inoltre possibile vendere console e giochi usati, previa valutazione dello staff o tramite un documento scaricabile online.
